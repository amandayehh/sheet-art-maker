# Sheet Art Maker
Create art in Google Sheets
<br>
<br>
<br>


## How to run this extension
1. In a Google Sheets file, select Extensions >  Apps Script.
<img width="100%" src="https://github.com/user-attachments/assets/ae51cbf9-a29e-4cdc-8313-a97b63397e95" />

2. In the Apps Script editor, copy and paste the Code.gs into the file with the same name.

3. Create a new HTML file called Sidebar.html, and make sure to use the same case. Copy and paste the html file in it.

4. Save both files.

5. In the editor sidebar, click “+” to a new service. Select “Google Sheets API”. This will unlock more robust copy and paste functionalities. (Optional) 
<img width="100%" src="https://github.com/user-attachments/assets/5f71ff93-843d-4ec0-b621-7bb63c62adb6" />

6. Go back to your sheets file. Refresh the page.

7. Click on Sheet Art Maker > Open Sheet Art Maker to enable the art sidebar.
<img width="100%" src="https://github.com/user-attachments/assets/1a035ee6-fba9-45a9-ad2f-60415d81a4b6" />

8. On the first run, you’ll need to enable permissions. Click to show advanced options and select the unsafe option. Don't worry. There is nothing suspicious about this app.
